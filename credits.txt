Clonk Rust
==========

Clonk Rust is a Rust port of LegacyClonk, developed for compatibility with
the original C++ game engine.

Rust port
---------

The repository history records all additional contributors to the Rust port.

LegacyClonk and Clonk Rage
--------------------------

Clonk Rust is derived from LegacyClonk and the Clonk Rage source code and game
content. Copyright remains with the respective authors and contributors,
including RedWolf Design GmbH and the LegacyClonk Team.

Core game content
-----------------

The core bundled game data comes from the LegacyClonk content project.
Individual scenario and definition groups may contain their own author and
attribution files. The complete content history is available at:
https://github.com/legacyclonk/content
