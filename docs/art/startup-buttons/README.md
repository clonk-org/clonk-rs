# Main-menu button art review

Open [the interactive comparison](index.html) to review the six main-menu button labels at different widths and in normal or pressed states. The page has separate draggable comparisons for the original versus HD button and the earlier HD grain versus the refined grain. The [original game render](implemented-buttons-before.png) and [HD game render](implemented-buttons.png) are matching 1280 × 720 captures cropped to the button column; the [full HD menu capture](implemented-menu.png) is also included. The [normal grain before/after](grain-before-after.png), [pressed grain before/after](grain-pressed-before-after.png), [normal original/HD comparison](before-after.png), [pressed original/HD comparison](pressed-before-after.png), [right-end nailhead detail](right-end-hd.png), and [full review-page capture](review-page.png) show the default `Exit` button. The supplied original game crop is [also included](original-game-capture.png). Append `?state=pressed` to the review-page URL to open it in the pressed state.

The Rust main menu now loads `planet/Graphics.c4g/StartupBigButtonHD.png` and `StartupBigButtonDownHD.png` (2052 × 160). The original 224 × 40 sprites remain for comparison and other classic GUI consumers. The earlier HD grain is in `button-normal-hd-v4.png` and `button-pressed-hd-v4.png`. The HD artwork was made with the built-in imagegen tool from the original sprites and the supplied screenshot, then cropped and masked to a continuous three-slice plank. The grain revision used imagegen for a wood-only blend that retains the approved plank alpha, rim, nails, and end geometry. The game renderer and review page both stretch the HD middle between 200-pixel source end caps drawn into 40-pixel display ends, keeping the fasteners square.

The static images on this page are rendered browser fixtures for comparing the art. The game uses the HD PNGs directly through its own three-slice renderer.
